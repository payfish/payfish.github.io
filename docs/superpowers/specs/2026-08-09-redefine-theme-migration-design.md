# Redefine主题迁移设计

## 目标

将现有Hexo博客从Fluid切换到官方Redefine默认主题，把现有文章放入Redefine的原生页面结构中，不额外定制首页布局。同时修复两篇新增AI学习文章的标题、日期、分类和失效图片。

## 已确认决策

- 使用官方npm包`hexo-theme-redefine@2.9.0`。
- 遵守并保留Redefine的`GPL-3.0`许可证声明。
- 使用Redefine默认首页、文章卡片流、文章页和导航样式。
- 不复制官方演示站的文章、品牌、广告和图片。
- 保留现有站点名称、文章内容、历史文章路径和GitHub Pages发布方式。
- Fluid主题文件暂时保留但不启用，等线上稳定后再单独清理。

## 主题迁移

1. 安装Redefine稳定版及其明确要求的渲染依赖。
2. 生成站点级`_config.redefine.yml`，只写本站需要的覆盖项。
3. 将根配置中的活动主题切换为`redefine`。
4. 配置站点标题、作者、中文语言、导航、分类、标签、归档、搜索、深色模式和代码高亮。
5. 保持现有Hexo生成和`hexo deploy`发布链路不变。

## 验证范围

- `npm ci`可在干净依赖环境安装。
- `hexo clean && hexo generate`完整生成成功。
- 首页、文章页、分类页、标签页、归档页和关于页均可访问。
- 两篇新增文章显示正确标题和日期。
- RAG文章不再包含Windows绝对路径或知乎图片热链。
- 页面内图片没有失败请求。
- 桌面和移动端无文字重叠、横向溢出或导航遮挡。
- 本地验证通过后再更新`source`分支和线上`master`。

- 迁移前记录当前提交。

- 不修改GitHub Pages仓库和发布分支结构。
